# Security Policy

Do not post active exploit details, private credentials or personal data in public Issues.
If you identify a security issue, contact the repository maintainer privately using the configured reporting channel. Set a repository-specific contact method before inviting external contributors.

Automated static analysis and AI review are defense-in-depth, not a security guarantee.

For release-review scope, source/test entry points and the reviewer outcome record,
see [the independent security review handoff](docs/SECURITY_REVIEW.md). The handoff
is preparation, not independent approval. If a working private reporting channel
has not been confirmed, ask the maintainer for one without disclosing sensitive
details in a public issue.
